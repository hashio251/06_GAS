# 出勤スケジュール同期の試作

勤務先の出勤スケジュールを個人用のGoogleスプレッドシートにも反映することを想定した、Google Apps Scriptの下書きです。

## 現在の状態

[`work.js`](work.js) では、`worksUrl` と `myUrl` に設定した2つのスプレッドシートを `SpreadsheetApp.openByUrl()` で開きます。`synchronizationSheet()` は空で、対象シートの選択・データ取得・書き込みは未実装です。

続けて実装する場合は、アクセス権があるテスト用スプレッドシートを用意し、URLのプレースホルダーを差し替えてから、コピーするシート名とセル範囲を決めます。
