# Gmail Auto Labeling & Cleanup

Google Apps Script（GAS）を使用して、Gmailのメール振り分けと不要メールの整理を自動化するスクリプトです。

送信元メールアドレスやメール本文などに含まれる文字列を条件に、指定したラベルを自動付与します。また、不要なメールを専用ラベルで管理し、まとめてゴミ箱に移動する機能も実装しています。

検索条件やラベル名を変更することで、さまざまなGmailアカウントで再利用できるようにテンプレート化しています。

## 制作背景

アルバイト先で使用しているメールボックスに、業務上必要なメールと不要な通知メールなどが混在しており、メールの管理に手間がかかっていました。

そこで、Google Apps Scriptを利用して、メールの振り分けや不要メールの整理を自動化する仕組みを作成しました。

また、プライベートのGmailでも同じ仕組みを利用したいと考え、メールアドレスやラベル名などの設定を変更するだけで再利用できるようにテンプレート化しました。

## 主な機能

### 1. メールの自動振り分け

`labelSorting()`

指定した条件に一致するメールスレッドに、Gmailのラベルを自動付与します。

以下の検索条件に対応しています。

- 送信元メールアドレスの一部による検索
- 複数の送信元メールアドレスによるOR検索
- 指定した文字列による検索
- 複数の文字列によるOR検索
- 既にラベルが付与されているメールの除外

検索結果と付与するラベルを、それぞれ配列で管理しています。

`forEach()`を利用して対応するラベルを付与することで、振り分け条件ごとに処理を記述する必要がない構成にしています。

また、一度に処理するスレッドを100件ずつに分割し、まとめてラベルを付与します。

### 2. 削除対象メールの確認

`previewDelete()`

`_deleteTarget` ラベルが付与されたメールスレッドの件名をログに出力します。

- 削除対象のスレッドを最大100件取得
- 対象件数をログに表示
- 各スレッドの件名をログに表示
- ゴミ箱内のスレッドを検索対象から除外

実際にゴミ箱へ移動する前に、対象メールを確認するための機能です。

### 3. 不要メールの一括整理

`messageDelete()`

`_deleteTarget` ラベルが付与されたメールスレッドを、まとめてゴミ箱に移動します。

- 対象スレッドを100件ずつ取得
- 取得したスレッドをゴミ箱に移動
- 対象がなくなるまで繰り返し処理
- 処理したスレッドの合計件数をログに表示

メールを直接完全削除するのではなく、Gmailのゴミ箱へ移動する仕組みにしています。

## 使用技術

- Google Apps Script（GAS）
- JavaScript
- GmailApp（Gmailサービス）

## 使い方

### 1. Google Apps Scriptのプロジェクトを作成

[Google Apps Script](https://script.google.com/) にアクセスし、新しいプロジェクトを作成します。

作成したプロジェクトにスクリプトを貼り付けます。

### 2. Gmailのラベルを作成

振り分け先となるラベルをGmail側で作成します。

親ラベルと子ラベルを使用する場合は、以下のような階層構造で作成します。

```text
Gmail
├── 仕事
│   ├── お知らせ
│   └── 通知
├── プライベート
│   └── メルマガ
└── _deleteTarget
```

※ ラベルが存在しない場合、スクリプト側では自動作成されません。

### 3. 検索条件を設定

振り分けたいメールの条件を設定します。

**送信元メールアドレスで検索する場合**

```javascript
const inAdress1 = GmailApp.search(
  'from:example@example.com -label:仕事/お知らせ'
);
```

**複数の送信元メールアドレスで検索する場合**

```javascript
const inAdreesOR1 = GmailApp.search(
  'from:{example1@example.com example2@example.com} -label:仕事/通知'
);
```

**指定した文字列で検索する場合**

```javascript
const inText1 = GmailApp.search(
  '"検索したい文字列" -label:プライベート/メルマガ'
);
```

**複数の文字列でOR検索する場合**

```javascript
const inTextOR1 = GmailApp.search(
  '{"文字列1" "文字列2" "文字列3"} -label:_deleteTarget'
);
```

`-label:` を指定することで、対象ラベルが既に付与されているメールを検索対象から除外できます。

### 4. 付与するラベルを設定

検索条件に対応するラベルを取得します。

```javascript
const inAdressLabel1 =
  GmailApp.getUserLabelByName('仕事/お知らせ');
```

検索結果とラベルを、それぞれ配列に設定します。

```javascript
const inLabelList = [
  inAdress1,
  inText1
];

const labelList = [
  inAdressLabel1,
  inTextLabel1
];
```

※ 上記は設定例です。実際には使用する検索条件とラベルの変数を設定してください。

**2つの配列は同じ順番で指定する必要があります。**

### 5. スクリプトを実行

Google Apps Scriptの実行メニューから、目的に応じた関数を選択します。

| 関数名 | 処理内容 |
| --- | --- |
| `labelSorting()` | メールの自動振り分け |
| `previewDelete()` | 削除対象メールの確認 |
| `messageDelete()` | 不要メールをゴミ箱へ移動 |

初回実行時には、Googleアカウントによるアクセス権限の承認が必要です。

不要メールを整理する場合は、`previewDelete()` で対象を確認してから、`messageDelete()` を実行してください。

## 実装上の工夫

### 配列とforEachによる処理の共通化

検索結果とラベルを配列で管理することで、同じ振り分け処理を繰り返し記述する必要がない構成にしています。

振り分け条件を追加する際も、検索条件とラベルの設定を追加することで対応できます。

### 大量メールへの対応

GmailAppの `addToThreads()` や `moveThreadsToTrash()` を利用し、100件ずつまとめて処理しています。

削除処理では、対象スレッドがなくなるまで繰り返し検索と移動を実行します。

※ GmailAppの実行時間やサービスの利用制限により、大量のメールを一度に処理できない場合があります。

### 誤削除を防ぐための処理分離

不要メールの整理を、ラベル付与・削除対象の確認・ゴミ箱への移動の3段階に分離しています。

これにより、対象メールを確認せずに削除処理を実行してしまうリスクを減らしています。

## 注意事項

- ラベル名はGmail上に存在するものを正確に指定してください。
- GmailAppの検索結果とラベル付与・ゴミ箱への移動は、スレッド単位で処理されます。
- `messageDelete()` を実行すると、対象スレッド全体がゴミ箱へ移動します。
- Gmailのゴミ箱に移動したメールは、通常30日後に自動的に完全削除されます。
- スクリプト実行前に、検索条件や削除対象を十分に確認してください。
- 検索条件とラベルの配列は、必ず対応する順番で設定してください。
- 現在のコードでは、検索処理がグローバルスコープにあるため、いずれの関数を実行する場合も検索処理が評価されます。
